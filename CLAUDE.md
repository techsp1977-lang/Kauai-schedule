# Kauai Urgent Care schedule site

- `index.html` holds the page design (CSS, login, rendering code). Edit it for any design change, then commit and push to `main`.
- `schedule.json` holds the schedule data. It is overwritten every ~30 minutes by the Apps Script on the "Makana Master schedule" Google Sheet. Never hand-edit it; changes come from the sheet.
- The page loads `schedule.json` at runtime (`{lastUpdated, years}`), so design changes and data syncs never collide.
- Before pushing, `git fetch origin main && git rebase origin/main`, since the sync commits often.
- Label column: `.thl` (header) / `.tdl` (row labels). Shift labels must stay on one line on desktop/tablet. On phones (≤767px) the label column is sticky (stays visible while swiping across days), narrower (122px) and labels may wrap to two lines.
- Mobile layout (≤767px): header wraps to two rows (title + Today/Sign Out, then a full-width year toggle); `.topbar` wraps header + month tabs so both stay pinned together; blank columns for days from the neighbouring month (`.emp`) are hidden.
- Provider colors live in `index.html`: `KEY_PROVIDERS` are the dark, white-text colors for Mileka, Kaitlyn, Sabrina (HAAS in the sheet; charcoal, not green, so it never matches the green shift labels), Rova and Adams; `MID_PROVIDERS` are medium colors for Ted, Proctor, Gretchen, Hayes and Schenfeld; `LIGHT_PROVIDERS` are fixed light colors for Greg, Morris, Lombardi and Bryant. Closed cells are light gray with red text. `PALETTE` holds muted colors for everyone else; `buildColors` picks each one to clash least (by hue, partly lightness, via `cdist`) with everyone working the same months, weighted by how many months they share. Avoid giving people who share months shades of the same color. `ALIASES` maps alternate spellings. The `color` values in `schedule.json` are ignored.
